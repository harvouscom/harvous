# Version 2.10.0

**Release Date**: July 31, 2026

## Features

- Realtime Authorization: private Broadcast/Presence channels via RLS on `realtime.messages` (`supabase/realtime-authorization.sql`, `npm run db:realtime-auth`)
- Live co-edit bodies: size-capped `{title,content,updatedAt,spaceId:null}` patches on co-edited, non-encrypted notes
- Keyed invalidation debounce + 120ms fast lane for live-body payloads

## Notes

- After deploy, turn OFF Supabase Realtime "Allow public access" (manual dashboard step)
- Clerk JWT template `supabase` must include `"role": "authenticated"`
