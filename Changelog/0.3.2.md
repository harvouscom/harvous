# Version 0.3.2

**Release Date**: May 18, 2026

## Fixes

- Center folder icon in iOS navigation bar glass orb when no folder is assigned (icon-only chip now uses a 44 pt square tap target, eliminating the off-center appearance caused by asymmetric toolbar padding)
- Match folder chip circular orb on macOS to the compose button by removing the explicit bordered button style when no folder is assigned, letting the system toolbar chrome handle sizing
- Require stronger context for folder tag suggestions — keywords must appear in the title or repeat in the body before surfacing as a folder suggestion, reducing noise
- Conditionally render the remove button on inspector tag chips only when the removal state is visible, preventing invisible hit targets from intercepting taps
