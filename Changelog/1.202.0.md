# Version 1.202.0

**Release Date**: March 26, 2026

## Features

- **TipTap v3.20.5 upgrade** — Aligned all `@tiptap/*` packages from v3.6.5 to v3.20.5, fixing version mismatch that caused BubbleMenu failures
- **Selection action bar** — Highlight text to see a floating toolbar with "Create Note" and "Copy" actions (replaces old BubbleMenu button)
- **Inline translation picker** — Click any scripture pill in edit mode to change its Bible translation via a compact horizontal picker
- **Per-pill translation override** — Typing "John 3:16 ESV" now correctly uses the specified translation server-side instead of the user's default
- **Translation abbreviation on cards** — Scripture-type notes show translation badge (e.g., "ESV") next to the reference on condensed note cards

## Technical Changes

- Replaced TipTap BubbleMenu with custom floating toolbar using `createPortal` + `selectionUpdate` listener
- Changed `prosemirror-state` imports to `@tiptap/pm/state` across all custom extensions
- Added `mergeNestedSpanStyles: false` to editor config to preserve pill HTML attributes
- Pinned `@vitejs/plugin-react` to `~5.1.4` to prevent Vite 8 (requires Node 22+)
- Unified floating picker styles — both translation picker and selection action bar share animation, shadow, and button treatment

## Bug Fixes

- Fixed missing space after scripture pill creation (cursor no longer snaps back inside pill)
- Fixed pill mark bleeding into subsequent typed text after pill creation
- Fixed translation revert when pills are re-processed
- Fixed stale scripture note content after inline translation change (awaited API instead of fire-and-forget)
