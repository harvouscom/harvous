# Version 2.9.1

**Release Date**: July 31, 2026

## Fixes

- Native note pushes now send `expectedVersion` (was unconditional last-write-wins against web/other devices)
- Explicit 409 handling on native flush: server-wins rebase instead of permanent syncError / retry deadlock
- Co-edited shared-space notes are read-only on native (title + body); flush skipped; sync guard never blocks remote refresh for followers
- Unblocks macOS build: `FolderSubjectEnrichment` concurrency/`ComparisonResult` typos and `LifeKeywordContextGate` if-condition

## Notes

- Collaborative editing (pass-the-pen) shipped in 2.9.0; this patch completes the native side of that story without joining the pen lease on Mac/iOS
