# Version 1.59.0

**Release Date**: February 1, 2026

## Lock notes with PIN

- Lock any note with a 4-digit PIN; content is encrypted before saving
- Unlock in-session to view and edit; lock again or close the app to re-protect
- Change PIN or remove lock from the note’s More menu (confirm current PIN when changing or removing)
- Locked notes cannot be shared via link until the lock is removed

## Other Changes

- Referral system and UX improvements from 1.58.x
