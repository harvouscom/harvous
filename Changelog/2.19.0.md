# Version 2.19.0

**Release Date**: August 4, 2026

## Features

- Church org: teaching calendar — staff plan services ahead (date, title, passage, series, starter template) from the My Church hub, role-gated on the `sermon_tools` capability
- Church org: "This Sunday" on Home — connected congregants see the next planned service and start a note on it in one tap, with the passage as a live scripture pill and the church's own template already in the body
- Note lineage: `Notes.startedFromServiceId` / `startedFromServiceTitle` record which service a note came from. The congregant's own row — no church-facing route reads it, and nothing aggregates over it

## Improvements

- Daily passage sheet: the add action moved from a floating accent circle into the footer, so it can no longer overlap the translation copyright — which it did at every width, because its clearance padding was overridden by a later `padding` shorthand
- Daily passage sheet: the translation credit wraps instead of truncating mid-word
- New shared `proto-glass-action` control, with a blue-gradient `--primary` variant, so "make a note from this passage" looks like one thing wherever it appears
- Church staff roster: role is carried by icon silhouette and badge rather than per-row accent colours, so one roster reads as one roster

## Other Changes

- Church plan repriced to **$30/mo · $216/yr** — a 40% annual break, replacing "two months free" (~16.7%). No church had ever paid at the old price; Polar church products are still unconfigured, so checkout remains deliberately gated

## Notes

Church surfaces stay gated at every entry point: a `Churches` row must be
admin-registered, congregant surfaces need `UserMetadata.connectedOrgId`, and
staff surfaces need Clerk org membership. A user with no church sees no church
UI at all. A lapsed plan blocks staff writes only — everything already planned
stays visible and everyone keeps their notes.
