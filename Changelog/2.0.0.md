# Version 2.0.0

**Release Date**: July 6, 2026

## Harvous 2.0

Classic SPA retirement — the native-like prototype shell is now the sole authenticated web client (`20162b65`, June 30, 2026). Legacy Classic URLs redirect to prototype routes.

## Features

- Native-like web shell: glass sidebar, inspector, study docks, folders-first organization
- Home recall carousel, generative resurfacing, and study arcs (memory layer)
- Offline sync for highlights, pin, and study-thread connections
- Mobile sidebar card dismiss and thread-review action fixes

## Improvements

- Rate limits on public share and invitation read endpoints
- 50MB cap on user import uploads
- Appearance preset catalog updates and new hero/background assets

## Note on version history

`1.217.x` (May–July 2026) was an internal high-frequency patch train. February 2026 `2.0.0`–`2.0.3` changelogs are archived under `Changelog/legacy-2026-02/`.
