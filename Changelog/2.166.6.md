# Version 2.166.6

**Release Date**: September 4, 2026

## Features

- Finish a study plan yourself, apart from a leader closing it for the group
- A personal reading plan can be finished too, not only one shared with a group
- A second leader in any shared space, not only rooms connected to a church
- Reply to someone else's highlight from the highlight itself
- A shared space shows who else is there
- Set aside the passage on a space's showing-up card, and it moves to the next one your group has cited most
- Open a passage in the reader from "Coming up", alongside writing about it
- "New gathering" schedules onto the next meeting date; the Ideas column is what makes something undated
- A planner that is read-only says so in every view, including calendar and series
- See the shape of what a gathering's notes will start with before you publish it
- Reading a church room's full teaching plan takes a leader or the owner

## Fixes

- Search results say what each row is — a note, a folder, a Thread, a highlight, a book, a passage
- A shared link is a row, not a config block

## Other Changes

- The shared-space contracts read the file that still exists
