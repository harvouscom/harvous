# Version 3.3.3

**Release Date**: September 5, 2026

## Features

- Reminders: an optional nudge on Sunday morning and once midweek, carrying the day's verse
  or the chapter you left, opening straight to it. Works in desktop browsers, installed web
  apps, and on Android and iPhone once Harvous is added to the Home Screen. Set it up under
  Settings, Reminders.
- Reminders stay quiet when they should. Never more than two a week, never on a day you have
  already opened Harvous, and they pause themselves if they go unopened for a few weeks.

## Notes

Not enabled on the server yet — reminders need VAPID keys and the push schema applied before
anyone can turn them on.
