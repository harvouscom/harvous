# Version 2.55.0

**Release Date**: August 13, 2026

## Features

- Say when and where a shared space meets, and see it on the space's About card
- Start a space's Planner on the day that space actually gathers
- Reorder the notes in a Thread by touch, not only with a mouse
- Keep a Thread's order without turning it into a study plan
- Show Threads in the same grouped card the rest of the app uses

## Fixes

- Stop the empty state flashing before the loading indicator on Thread lists

## Improvements

- Grow the Add resource button into its panel instead of swapping it

## Documentation

- Scope multiple meeting days, meeting kind, and calendar
