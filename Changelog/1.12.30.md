# 1.12.30

## Fixes

- **Scripture Notes Sorting**: Auto-created scripture notes now appear at the top of lists as fresh content
  - Fixed missing `lastVisited` timestamp when creating scripture notes via `processScriptureReferences`
  - Removed aggressive race condition filters that were hiding newly created scripture notes
  - Extracted `getOrCreateScriptureNote` to shared utility to prevent scripture note duplication
  - Updated `CardFullEditable` to use shared utility for scripture pill clicks

When you create a note containing a scripture reference (e.g., "John 3:16"), the system now properly sets the `lastVisited` timestamp on auto-created scripture notes, ensuring they appear at the top of your lists where fresh content belongs.
