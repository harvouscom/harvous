# Version 2.54.8

**Release Date**: August 13, 2026

## Fixes

- Open the editor immediately when adding a note from today's passage, a sermon starter, or a Home suggestion
- Present Home once its data has settled, instead of rearranging cards as each query lands
- Stop a Home suggestion from appearing twice in the same set
- Show a loading state when opening a section of Settings, rather than an empty panel
- Begin loading a Settings section on touch down instead of on tap release
- Stop a list row staying highlighted after the note opened from it is closed
