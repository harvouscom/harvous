# Version 2.21.0

**Release Date**: August 6, 2026

## Features

- Church settings: a church stores its own time zone and its recurring service times, so a service reads as the church's wall clock rather than the viewer's
- Teaching plan: a ministry channel or church shared space can carry its own plan, so Youth's Wednesdays live beside the church's Sundays instead of competing with them
- Teaching plan: a series is a real thing now rather than a repeated label. Renaming one renames it on every sermon that shows it, and a series opens to show its whole run
- Teaching plan: "Repeat weekly" plans a run in one pass instead of thirteen trips through the editor. It stops at the first week already spoken for and says which
- Church team: a connected congregant can be granted leadership of a single space, letting a volunteer run the channel they lead without taking a staff seat
- Church hub: an Engagement pane showing how many people are connected and how many follow each channel. Counts only, and it says so

## Improvements

- Church roles: Pastor and Teacher are now different jobs. A pastor sets the teaching plan and the church's note templates; a teacher sees the plan they teach from and publishes to channels. The two roles previously granted exactly the same thing
- Church roles: every role carries its own icon in the roster, the member sheet, and the invite picker, so a role reads by silhouette rather than by which of two icons it happened to get
- Church hub: "Teaching plan" is now "Planner", and "Staff tools" is now "Tools"

## Fixes

- Teaching plan: a church whose plan has lapsed can see what it already planned again. The staff read was returning 402 on a lapse despite lapsing being a write gate, which left the pane blank instead of read-only
- Teaching plan: removing a sermon now frees the service times it held. Those claims were being left behind, which silently blocked that service time on that date for good

## Other Changes

- Every icon now comes from the Font Awesome package rather than a hand-copied path
