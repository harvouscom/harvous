# Version 3.17.0

**Release Date**: October 2, 2026

## Features

- Connector `start_note`: start a new, empty note from an AI chat, with the app's summary, passages and open question in a removable "From your Claude chat" card. Create-only, 20 a day, with an off switch in Settings › Connector
- Connector read tools: `where_i_left_off`, `list_notes_in_thread`, `passage_context`; two new prompts, and tool descriptions led by the phrases people use
- Note side panel: a "Started in" row for notes an AI app started
