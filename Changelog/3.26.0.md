# Version 3.26.0

**Release Date**: October 22, 2026

## Features

- Share a Thread by link. The Threads popover and the Library panel's Thread view end in a blue Share Thread button that makes the link and copies it in one press, then shows the link in the same place, with View public page, Get a new link, Stop sharing and Share with others on Harvous. No second dialog.
- Shared Thread links stay up to date as you connect notes, and locked notes never show.
- The public shared Thread page now reads like a Thread in the app: the Thread tile, a trail of its notes, and the same spacing as a shared note.
- Thread links appear in Settings › Sharing, where they can be copied, replaced or turned off.
