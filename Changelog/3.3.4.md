# Version 3.3.4

**Release Date**: September 5, 2026

## Internal

Development tooling only — nothing in this version changes the app for anyone using it.

- The app recognises HTTPS development tunnels as first-class hosts, so it serves the real
  2.0 app over one instead of falling through to Classic. Needed because a phone cannot reach
  a dev server any other way: service workers and Web Push require a secure context, which a
  LAN address is not.
- Vite's dev and preview servers accept tunnel hostnames.
