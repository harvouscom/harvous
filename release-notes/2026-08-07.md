# What's New in Harvous — August 7, 2026

**Release Date:** August 7, 2026
**Version:** v2.34.0

Import, rebuilt. If your notes are in Obsidian, Notion, Evernote, Apple Notes or a folder of Word documents, you can bring the whole lot over and watch it arrive.

---

## Updates in This Release

### Bring your notes in from wherever they already live

**What changed:**

- Drop files onto the import screen, or a whole folder, or a Harvous backup
- Every file becomes a row that says what it will turn into — how many notes, how many highlights, which folder they will land in — before anything is created
- Untick anything you would rather leave behind
- Each row shows its own progress as it uploads, then as its notes are created, then as scripture references are linked
- Files already in your library are recognised and skipped rather than duplicated
- Evernote exports work now. The `.enex` format was listed as accepted for months and quietly imported nothing

**How it helps you:**

- You can see what an import will do to your library before it does it
- A big move no longer looks like a frozen screen, because each file reports for itself
- Re-importing the same backup is safe: nothing is duplicated, and the summary says so plainly

### An import that survives a big library

**What changed:**

- Files are read one at a time rather than all in one request, so a large import no longer runs out of time partway
- If the server asks us to slow down, the import waits and picks back up on its own instead of stopping
- Stop pauses the run and Continue resumes it from where it left off
- Reloading the page mid-import picks the session back up
- A finished import can be undone in one click, and notes you have already edited are kept

**How it helps you:**

- Hundreds of notes arrive in one go instead of failing at the point the old importer gave up
- Nothing is lost to a slow connection or a closed tab

### My Data, in three parts

**What changed:**

- Settings, My Data is now Import, Export and Danger zone
- Import happens inside that panel, and the panel will not close while an import is running
- Export is unchanged: full backup, Markdown or CSV

**How it helps you:**

- Everything to do with getting notes in or out is in one place
- A stray click cannot cancel an import halfway through

### Smaller things

**What changed:**

- Check marks across the app are the quieter mark used on the pricing page. Blue is now reserved for a choice you have made, like your default translation, rather than for a list of what a plan includes
- Menus read a little heavier, matching the rest of the app

---

## Tips

- The fastest way in is to drag a folder straight onto the import panel; the folders inside it come across as they are
- Exporting a full backup first is a good habit before a large import, so undo is never the only way back
