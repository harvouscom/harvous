# What's New in Harvous v0.3.2

**Release Date:** May 2026
**Version:** 0.3.2 (Mac DMG)

This release focuses on polish — getting the small visual details right so the Mac and iOS apps feel consistent and intentional.

---

## Updates in This Release

### Folder chip alignment

**What changed:**
- On iOS, the folder icon in the navigation bar now sits perfectly centered in its circular button when no folder has been assigned to a note
- On Mac, the folder icon orb now matches the round shape of the compose button

**How it helps you:**
- The toolbar looks visually consistent whether or not a note belongs to a folder
- No more subtle off-center icon that draws the eye for the wrong reason

### Smarter folder suggestions

**What changed:**
- Folder tag suggestions now require the keyword to appear in the note title or repeat at least twice in the body before being offered

**How it helps you:**
- You see fewer low-confidence suggestions cluttering the folder picker
- When a folder is suggested, it is more likely to be the right one

### Tag chip remove button fix

**What changed:**
- The remove button on inspector tag chips is now only present in the view when the removal state is actually showing

**How it helps you:**
- Tapping in the area of a tag chip no longer accidentally triggers a hidden remove action

---

## Need Help?

If you have questions about any of these updates:
- Most features have tooltips — hover over buttons on Mac to see what they do
- On iOS, long-press on elements to discover actions
