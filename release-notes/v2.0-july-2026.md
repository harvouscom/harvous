# What's New in Harvous 2.0

**Release Date:** July 2026  
**Version:** 2.0.0

Harvous 2.0 is here. The app you have been using on web and mobile is now the main Harvous experience — faster, calmer, and built around folders and connected study threads instead of the old Classic layout.

---

## Updates in This Release

### A new home for your notes

**What changed:**
- The native-like web shell is now the only signed-in web experience.
- Classic dashboard routes redirect automatically to the new note-centric URLs.
- Folders replace the old thread piles in the sidebar; study threads are for connected notes you are actively tracing.

**How it helps you:**
- One consistent layout on web that matches the Mac and iOS apps.
- Less hunting through hierarchy — open a note, use the sidebar, stay in flow.
- Your existing notes, folders, and highlights are the same data; only the shell changed.

### Smarter Home surfacing

**What changed:**
- Recall carousel on Home suggests notes, highlights, and themes worth revisiting.
- You can tap "Not now" to snooze a suggestion without opening it.
- Today's passage, founder letter, and other Home cards are easier to dismiss on mobile.

**How it helps you:**
- Gentle prompts to return to meaningful work without inbox noise.
- You stay in control of what resurfaces and when.

### Reliability and polish

**What changed:**
- Offline support expanded for highlights, pinning, and study-thread connections.
- Public share links and invitation pages are rate-limited for stability.
- Import uploads are capped at 50MB to protect performance.

**How it helps you:**
- Notes stay usable when connectivity is spotty.
- Fewer surprises when sharing or importing large libraries.

---

## Tips for the new shell

### Sidebar and folders
- **Quick tip:** Use the list mode menu to switch between Notes, Folders, Highlights, and Scripture.
- **Pro tip:** Drag notes into folders from the sidebar; study threads appear when you connect notes in the editor.

### Home cards
- **Quick tip:** Tap "Not now" or "Dismiss" on any Home card you do not need today.
- **Pro tip:** Recall suggestions rotate daily — snoozing one rests it for a few weeks.

---

## Need help?

If something from Classic looks missing, check whether it moved to folders, the inspector, or Settings. Legacy thread data was migrated to folders on first visit.

For support, use Settings → Support — the app version now shows **2.0.0**.
