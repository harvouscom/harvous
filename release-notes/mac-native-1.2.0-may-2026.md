# Harvous for Mac 1.2.0 (preview DMG)

**Release Date:** May 2026  
**Version:** 1.2.0 (macOS app bundle; unsigned preview)

This release updates the **native Mac app** version string and ships a fresh preview disk image. Pair it with the in-app and web updates you use day to day.

---

## Updates in This Release

### Visual polish

**What changed:**

- Scripture pills and linked-note capsules use the same soft inner-edge treatment as connection pills for a consistent, readable chip chrome.

**How it helps you:**

- Pills feel a bit more settled on the page without looking heavy or distracting from your notes.

---

### Packaging

**What changed:**

- Preview DMG builds use a universal Release binary (`arm64` and `x86_64`) when built with `package-dmg.sh` or `release.sh`.

**How it helps you:**

- The same download runs on Apple Silicon and Intel Macs.

Install notes for unsigned previews (quarantine, Gatekeeper): see `help/mac-native-app.md`.
