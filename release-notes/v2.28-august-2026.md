# What's New in Harvous v2.28.1

**Release Date:** August 6, 2026
**Version:** 2.28.1

This release includes improvements to navigation, organization, and overall user experience.

---

## Updates in This Release

### General improvements

**What changed:**
- Attach library resources to a planned entry
- One date tile, used everywhere a plan row appears
- Give the catalog's empty state the whole panel
- Give every tools pane its own load state
- Stop asking Clerk for the same roster four times a pane
- LibraryItems writes files too, not only links

**How it helps you:**
- Makes your Bible study workflow smoother
- Enhanced overall experience
- Smoother, more reliable experience
