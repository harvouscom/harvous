# What's New in Harvous v1.202.0

**Release Date:** March 26, 2026
**Version:** 1.202.0

A major editor upgrade that brings a smoother, more polished Bible study experience with better translation controls and new text actions.

---

## Updates in This Release

### ✨ Selection Action Bar

**What changed:**
- Highlight any text in a note to see a floating toolbar with quick actions
- "Create Note" extracts your selection into a new note instantly
- "Copy" copies the selected text to your clipboard
- More actions coming soon

**How it helps you:**
- Faster workflows — no more right-clicking or menu diving to act on selected text

### ✨ Inline Translation Picker

**What changed:**
- Click any scripture pill while editing to see a compact translation picker
- Switch between translations (KJV, NKJV, ESV, NIV, NLT, NET, BSB) right inline
- The picker auto-scrolls to show your current translation

**How it helps you:**
- Compare translations without leaving your note — just tap the pill and pick

### ✨ Per-Pill Translation Override

**What changed:**
- Type "John 3:16 ESV" and the pill uses ESV regardless of your default translation
- Each scripture pill remembers its own translation independently

**How it helps you:**
- Mix translations within a single note for side-by-side study

### ✨ Translation Badge on Note Cards

**What changed:**
- Scripture-type notes now show the translation abbreviation (e.g., "ESV") next to the reference title
- Visible on dashboard cards, included notes sections, and space content lists

**How it helps you:**
- See at a glance which translation a scripture note uses without opening it

### ✨ Editor Engine Upgrade

**What changed:**
- Upgraded the editor engine (TipTap) from v3.6.5 to v3.20.5
- Polished floating UI with subtle spring animations and softer shadows

**How it helps you:**
- Smoother typing, more reliable text selection, and a more refined feel throughout the editor

---

## Bug Fixes

- Fixed spacing after scripture pills — text typed after a pill now preserves the space correctly
- Fixed pill formatting from "leaking" into surrounding text
- Fixed translation changes not updating immediately when switching via the pill picker
- Fixed scripture notes sometimes using wrong translation when created with an override

---

## Tips for Using New Features

- **Select text** in any editable note to see the new action bar appear below your selection
- **Click a scripture pill** while editing to quickly switch its translation
- **Type a translation abbreviation** after a scripture reference (e.g., "Romans 8:28 KJV") to override your default
