# What's New in Harvous v1.126.6

**Release Date:** February 16, 2026
**Version:** 1.126.6

This release includes improvements to navigation, organization, and overall user experience.

---

## Updates in This Release

### ⚡ Performance

**What changed:**
- Move all routing to public/_redirects, purge edge cache

**How it helps you:**
- Smoother, more reliable experience

### ✨ General Improvements

**What changed:**
- Remove all catch-all redirects, let SSR function route natively
- Rename SPA index.html to app.html so /api/* hits SSR natively

**How it helps you:**
- Smoother, more reliable experience
