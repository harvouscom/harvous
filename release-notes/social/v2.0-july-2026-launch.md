## In-app featured card (admin API)

Run when the API is up (`npm run dev` locally or production). `contentType: church` for founder-style announcements.

```bash
curl -s -X POST "${API_BASE:-http://localhost:3001}/api/admin/featured" \
  -H "Authorization: Bearer $HARVOUS_ADMIN_SECRET" \
  -H "Content-Type: application/json" \
  -d '{
    "contentType": "church",
    "title": "Harvous 2.0",
    "description": "The web app is now the same calm, note-first experience as Mac and iOS. Classic is retired — your notes are unchanged. Read what is new.",
    "color": null,
    "isActive": true
  }'
```

Production: set `API_BASE=https://app.harvous.com` (or your production API host).

Deactivate when the campaign ends:

```bash
curl -s -X PATCH "${API_BASE}/api/admin/featured/{ITEM_ID}" \
  -H "Authorization: Bearer $HARVOUS_ADMIN_SECRET" \
  -H "Content-Type: application/json" \
  -d '{"isActive": false}'
```

Note: Featured cards surface on flows that still mount `FeaturedCarousel` (legacy dashboard paths). Prototype Home uses recall cards and founder letter instead — pair this with release notes for full reach.
