# What's New in Harvous v1.216.12

**Release Date:** April 25, 2026
**Version:** 1.216.12

This release includes improvements to navigation, organization, and overall user experience.

**What changed:**
- Conditional note list — peeks in on browse, collapses on select

**How it helps you:**
- Makes your Bible study workflow smoother

### Navigation improvements

**What changed:**
- Use .doubleColumn to hide note list while keeping sidebar visible

**How it helps you:**
- Smoother, more reliable experience
