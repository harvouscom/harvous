# What's New in Harvous v1.216.13

**Release Date:** April 26, 2026
**Version:** 1.216.13

This release includes improvements to navigation, organization, and overall user experience.

## Updates in This Release

### Navigation improvements

**What changed:**
- Two-column layout — sidebar navigates, no middle column
- Match note list background to sidebar style on macOS
- Use .doubleColumn to hide note list while keeping sidebar visible

**How it helps you:**
- Easier to find and access your content
- Smoother, more reliable experience
