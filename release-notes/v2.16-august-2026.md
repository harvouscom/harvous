# What's New in Harvous v2.16.0

**Release Date:** August 4, 2026
**Version:** 2.16.0

This release includes improvements to navigation, organization, and overall user experience.

## Updates in This Release

### General improvements

**What changed:**
- Serialize saves per note so overlapping writes can't self-conflict

**How it helps you:**
- Smoother, more reliable experience

### Visual polish

**What changed:**
- Keep a mid-compose note open across refresh, quiet the restore toast

**How it helps you:**
- Makes your Bible study workflow smoother
