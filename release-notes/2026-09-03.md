# What's New in Harvous — September 3, 2026

**Release Date:** September 3, 2026
**Versions:** v2.128.1

One fix to search, for a problem that looked like a much bigger one.

---

## Updates in This Release

### Search results say what each one is

**What changed:**

- Every result in the Library's search now carries a mark saying what it is: a note, a folder, a Thread, a highlight, a book, a passage
- Browsing already did this. Typing used to take the marks away
- Notes were the worst of it, wearing no mark at all once they were mixed in with other kinds
- The marks show up in the lists that hold more than one kind: the results on Everything, and the "everywhere else" group underneath any other tab

**How it helps you:**

- A folder and a Thread that happen to share a name read as two plainly different rows again, rather than as the same result twice
- Nothing was ever duplicated — search has always returned each thing once — but until now there was no way to tell that by looking
