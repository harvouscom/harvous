# Search and Find

Learn how to quickly find your notes and threads in Harvous using the powerful search functionality.

## How to Search

### Basic Search

1. **Click the search icon** in the top navigation or press `Cmd/Ctrl + F`
2. **Type your search query** in the search box
3. **View results** as you type (search happens in real-time)
4. **Click any result** to open it

### Search Features

- **Real-time results**: See results as you type
- **Full-text search**: Searches across all notes and threads
- **Title priority**: Title matches appear first
- **Content matching**: Searches note content and thread descriptions
- **Tag support**: Includes tag matching for comprehensive results

## Understanding Search Results

### Relevance Scoring

Search results are sorted by relevance:

1. **Title matches** (100+ points): Highest priority - exact matches in titles
2. **Tag matches** (75+ points): High priority - matches in tags
3. **Content matches** (50+ points): Medium priority - matches in note content
4. **Multiple occurrences**: Bonus points for multiple matches
5. **Recent content**: Slight boost for recently updated content

### Result Display

Search results show:
- **Note/Thread title**: The title of the matching item
- **Preview**: A snippet of the matching content
- **Context**: Which thread or space the item belongs to
- **Relevance**: Most relevant results appear first

## Search Tips and Tricks

### Finding Specific Notes

**By Title**
- Type the exact title or part of it
- Title matches get highest priority in results

**By Content**
- Type keywords from the note content
- Content matches appear in results

**By Note ID**
- Type the note ID (e.g., "N042")
- Search will find the specific note

### Using Keywords

**Specific Terms**
- Use specific biblical terms (e.g., "faith", "grace", "love")
- Use book names (e.g., "John", "Romans", "Psalms")
- Use verse references (e.g., "3:16", "John 3")

**Multiple Words**
- Type multiple words to narrow results
- All words must appear somewhere in the note/thread

### Search Patterns

**Exact Phrases**
- Search looks for word matches, not exact phrases
- Multiple words can appear anywhere in the content

**Case Insensitive**
- Search is not case-sensitive
- "FAITH" and "faith" return the same results

## Finding Notes by ID

Every note has a unique sequential ID (N001, N002, N003, etc.):

### How to Find by ID

1. **Type the note ID** in the search box (e.g., "N042")
2. **The specific note** will appear in results
3. **Click to open** the note directly

### Why Note IDs Matter

- **Easy reference**: "Check out my insight in N015" is clear
- **Study groups**: Reference notes in conversations
- **Quick access**: Find notes instantly by ID
- **Persistent**: IDs never change, even when reorganizing

## Using Tags in Search

### Tag Matching

Search includes tag matching for comprehensive results:

- **Auto-tags**: Notes are automatically tagged with biblical keywords
- **Tag search**: Search results include matches in tags
- **High priority**: Tag matches get high relevance scores (75+ points)

### Tag Examples

Common tags include:
- Biblical terms (faith, grace, love, prayer, etc.)
- Book names (John, Romans, Psalms, etc.)
- Themes (salvation, redemption, worship, etc.)

## Advanced Search Strategies

### Combining Search Methods

**Title + Content**
- Search for a specific term that might be in title or content
- Results show both types of matches

**ID + Keywords**
- Use note IDs for specific notes
- Use keywords for broader searches

### Organizing Search Results

**By Relevance**
- Most relevant results appear first
- Title matches before content matches
- Tag matches get high priority

**By Date**
- Recent content gets a slight boost
- Results also sorted by update date

## Search Limitations

### What Search Doesn't Do

- **Exact phrase matching**: Search looks for word matches, not exact phrases
- **Boolean operators**: No AND/OR/NOT operators (yet)
- **Date filtering**: Can't filter by date range (yet)
- **Advanced filters**: No filtering by space, thread, or tags (yet)

### Workarounds

- **Use specific keywords**: Be specific in your search terms
- **Browse by space/thread**: Use navigation to narrow results
- **Use note IDs**: Find specific notes instantly by ID

## Troubleshooting Search

### "I can't find my note"

1. **Check spelling**: Make sure you're spelling keywords correctly
2. **Try different terms**: Use synonyms or related words
3. **Search by ID**: If you know the note ID, search for it directly
4. **Browse manually**: Sometimes browsing is faster than searching

### "Search returns too many results"

1. **Be more specific**: Add more keywords to narrow results
2. **Use note IDs**: If you know the ID, search for it directly
3. **Browse by space/thread**: Use navigation to narrow your search

### "Search returns no results"

1. **Check spelling**: Make sure keywords are spelled correctly
2. **Try broader terms**: Use more general keywords
3. **Check "For You"**: The note might be unorganized
4. **Browse manually**: Sometimes browsing is necessary
