# Using Threads

Threads are collections of related notes within a space. Think of them as folders within your main drawers (spaces).

## What are Threads?

Threads are the middle level of organization in Harvous. They group related notes together within a space:

- **"Gospel of John Study"** - all your notes about John's Gospel
- **"Romans 8 Deep Dive"** - notes exploring Romans 8
- **"Daily Prayers"** - your prayer journal entries
- **"Prayer Requests"** - intercession list
- **"Sunday Sermons"** - notes from weekly services

## Creating a Thread

### Step-by-Step

1. **Click the "+" button** in the top navigation
2. **Select "New Thread"** from the dropdown
3. **Choose a space** (or leave unorganized for now)
   - You can organize it later if needed
4. **Add a descriptive title** for your thread
   - Make it clear what the thread is about (e.g., "Gospel of John", "Romans Study")
5. **Choose a color** from the 8 beautiful options:
   - Paper, Blessed Blue, Mindful Mint, Graceful Gold
   - Pleasant Peach, Caring Coral, Peaceful Pink, Lovely Lavender
6. **Click "Create Thread"** to save

Your thread will appear in the selected space with its unique color.

### Thread Features

- **Color coding**: Each thread gets a unique color for visual recognition
- **Note counts**: Shows how many notes are in the thread
- **Persistent navigation**: Recently accessed threads appear in your navigation sidebar
- **Many-to-many relationships**: Notes can belong to multiple threads

## Adding Notes to Threads

### When Creating a Note

1. **Click the "+" button** and select "New Note"
2. **Choose a thread** from the dropdown
3. **Add your note content**
4. **Click "Create Note"** - the note will be added to the selected thread

### Adding Existing Notes to Threads

1. **Open the note** you want to add
2. **Click the "More" menu** (three dots)
3. **Select "Edit"** or open the details panel
4. **Select the thread(s)** you want to add the note to
5. **Save your changes**

**Note**: Notes can belong to multiple threads! A note about "Faith" might belong to both "Romans Study" and "Personal Growth" threads.

## Managing Multiple Threads

### Organizing Threads in a Space

- **View all threads** by opening the space
- **See note counts** for each thread
- **Use colors** to quickly identify threads
- **Click any thread** to open it and see its notes

### Moving Threads Between Spaces

1. **Open the thread** you want to move
2. **Click the "More" menu** (three dots)
3. **Select "Edit"**
4. **Choose a new space** from the dropdown
5. **Save your changes**

The thread will move to the new space, but all its notes stay with it.

### Closing Threads from Navigation

- **Hover over a thread** in the navigation sidebar
- **Click the close button** (X) that appears
- The thread is removed from navigation but still exists in your spaces

## Thread Organization Tips

### Naming Your Threads

- **Be specific**: "Gospel of John" is better than "John"
- **Use consistent patterns**: "Romans Study", "John Study", "Psalms Study"
- **Include context**: "Sunday Sermons - January 2024" helps you find it later

### Organizing with Threads

1. **Group related notes**: Put notes about the same topic in one thread
2. **Use multiple threads**: Don't put everything in one thread - break it down
3. **Let threads evolve**: Add new threads as your study grows
4. **Use colors strategically**: Choose colors that help you quickly identify threads

## Many-to-Many Relationships

One of Harvous's powerful features is that **notes can belong to multiple threads**:

### Why This Matters

- **Cross-referencing**: A note about "God's love" might belong to both "Romans Study" and "Personal Growth"
- **Flexible organization**: Content isn't locked into rigid categories
- **Natural connections**: Bible study topics naturally overlap

### How It Works

1. **Create a note** in one thread
2. **Later, add it to another thread** using the note's edit panel
3. **The note appears in both threads** - no duplication needed
4. **Remove from one thread** - it stays in the other(s)

### Example

You create a note about "Faith" in your "Romans Study" thread. Later, you realize it also fits your "Personal Growth" thread. You can add it to both threads without creating a duplicate note.

## Thread Colors

Each thread gets a **unique color** for easy visual identification:

- Colors appear in navigation and thread headers
- Choose colors that help you quickly identify threads
- Colors are independent of space colors (spaces always use paper color)
