# Troubleshooting

Solutions to common problems and issues in Harvous.

## Common Issues

### "Where did my note go?"

**Possible causes:**
- Note is unorganized in "For You"
- Note is in a different thread than expected
- Note was moved to a different space

**Solutions:**
1. **Check "For You" tab**: Unorganized notes appear here
2. **Use search**: Search for the note by title or content
3. **Browse by thread**: Check the thread you assigned it to
4. **Browse by space**: Check the space it belongs to
5. **Search by ID**: If you know the note ID (e.g., N042), search for it

### "I can't find my note in search"

**Possible causes:**
- Misspelled keywords
- Note is unorganized
- Search terms don't match note content

**Solutions:**
1. **Check spelling**: Make sure keywords are spelled correctly
2. **Try different terms**: Use synonyms or related words
3. **Search by ID**: If you know the note ID, search for it directly
4. **Check "For You"**: The note might be unorganized
5. **Browse manually**: Sometimes browsing is faster than searching

### "My note isn't saving"

**Possible causes:**
- Internet connection issues
- Browser cache problems
- Temporary server issues

**Solutions:**
1. **Check your connection**: Make sure you're connected to the internet
2. **Try again**: Click "Save" again to retry
3. **Refresh the page**: A refresh can fix temporary issues
4. **Check for errors**: Look for error messages or notifications
5. **Clear browser cache**: Sometimes cache issues cause problems

### "I can't create a new note/thread/space"

**Possible causes:**
- Panel isn't opening
- Form validation errors
- Internet connection issues

**Solutions:**
1. **Check your connection**: Make sure you're connected to the internet
2. **Try keyboard shortcut**: Use `Cmd/Ctrl + N` for notes, `Cmd/Ctrl + Shift + N` for threads
3. **Refresh the page**: A refresh can fix temporary issues
4. **Check for errors**: Look for error messages or validation issues
5. **Try a different browser**: Sometimes browser-specific issues occur

## Navigation Issues

### "I can't navigate to a space/thread"

**Possible causes:**
- Item was closed from navigation
- Item doesn't exist
- Navigation cache issues

**Solutions:**
1. **Check "Full List" tab**: All spaces appear here
2. **Use search**: Search for the space or thread name
3. **Refresh the page**: A refresh can fix navigation issues
4. **Check if item exists**: The item might have been deleted or moved

### "My navigation sidebar is empty"

**Possible causes:**
- No recently accessed items
- Navigation was cleared
- Browser storage issues

**Solutions:**
1. **Access some content**: Navigation populates as you use the app
2. **Check "Full List" tab**: All your content appears here
3. **Use search**: Search for content you want to access
4. **Clear and refresh**: Sometimes clearing browser storage helps

### "I can't close an item from navigation"

**Possible causes:**
- Hover not working
- Close button not appearing
- Browser interaction issues

**Solutions:**
1. **Hover over the item**: Close button appears on hover
2. **Click the X button**: Click the close button that appears
3. **Try different browser**: Sometimes browser-specific issues occur
4. **Refresh the page**: A refresh can fix interaction issues

## Content Issues

### "I can't edit my note"

**Possible causes:**
- Edit mode not activated
- Note not loaded
- Browser interaction issues

**Solutions:**
1. **Click the edit button**: Or press `Cmd/Ctrl + E` to enter edit mode
2. **Refresh the page**: A refresh can fix loading issues
3. **Try keyboard shortcut**: Use `Cmd/Ctrl + E` for edit mode
4. **Check for errors**: Look for error messages
5. **Try different browser**: Sometimes browser-specific issues occur

### "My note formatting is wrong"

**Possible causes:**
- HTML rendering issues
- Editor display problems
- Content encoding issues

**Solutions:**
1. **Re-format the content**: Use the editor toolbar to fix formatting
2. **Refresh the page**: A refresh can fix display issues
3. **Check editor**: Make sure you're using the formatting toolbar
4. **Try different browser**: Sometimes browser-specific issues occur

### "I can't add a note to multiple threads"

**Possible causes:**
- Details panel not open
- Thread selector not working
- Many-to-many feature issues

**Solutions:**
1. **Open details panel**: Click "More" menu (three dots) and select "Edit"
2. **Select multiple threads**: Use the thread selector to choose multiple threads
3. **Save your changes**: Make sure you save after selecting threads
4. **Refresh the page**: A refresh can fix interaction issues

## Mobile-Specific Issues

### "Bottom sheet isn't opening"

**Possible causes:**
- Touch interaction issues
- Panel system problems
- Mobile browser issues

**Solutions:**
1. **Tap the button again**: Sometimes a second tap helps
2. **Check screen size**: Bottom sheet only shows on mobile (< 1160px)
3. **Refresh the page**: A refresh can fix interaction issues
4. **Try different browser**: Sometimes browser-specific issues occur

### "I can't dismiss the bottom sheet"

**Possible causes:**
- Swipe gesture not working
- Close button not visible
- Touch interaction issues

**Solutions:**
1. **Swipe down**: Swipe down on the bottom sheet to dismiss
2. **Tap outside**: Tap outside the sheet to dismiss
3. **Tap close button**: Look for the X button to close
4. **Press Esc**: On some devices, Esc key closes the sheet

## Getting More Help

### When to Contact Support

Contact support if:
- None of the solutions above work
- You encounter a bug or error
- You have a feature request
- You need additional assistance

### What to Include in Support Requests

When contacting support, include:
- **What you were trying to do**: Describe the action you were taking
- **What happened**: Describe what went wrong
- **Steps to reproduce**: List the steps that led to the issue
- **Device information**: Your device, browser, and OS
- **Screenshots**: If applicable, include screenshots of the issue
