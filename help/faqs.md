# Frequently Asked Questions

Common questions about Harvous and how to use it effectively.

## Getting Started

### What is Harvous?

Harvous is a Bible study notes application designed specifically for organizing your spiritual study. It uses a hierarchical system (Spaces → Threads → Notes) to help you organize, remember, and keep findable what you learn.

### How do I sign up?

Visit the Harvous app and sign in with your account using Clerk authentication. Your notes are private and secure - only you can see them.

### Is Harvous free?

Harvous is currently in development. Check the app for current pricing and availability.

### Can I use Harvous on mobile?

Yes! Harvous works great on mobile, tablet, and desktop. It's a Progressive Web App (PWA), so you can install it on your phone for an app-like experience.

## Organization

### What's the difference between Spaces, Threads, and Notes?

- **Spaces**: Top-level containers (like main drawers) - e.g., "Bible Study", "Prayer Journal"
- **Threads**: Collections within spaces (like folders) - e.g., "Gospel of John", "Romans Study"
- **Notes**: Individual pieces of content (like documents) - e.g., "John 3:16 Reflection"

### Can notes belong to multiple threads?

Yes! This is one of Harvous's powerful features. A note about "Faith" might belong to both "Romans Study" and "Personal Growth" threads. This reflects how Bible study topics naturally overlap.

### What is "For You"?

"For You" is your inbox - a capture zone for quick note-taking and unorganized content. It shows notes that aren't in any thread yet, and threads that aren't in any space yet. Perfect for quick capture and later organization.

### How do I organize my content?

You can organize in two ways:
1. **Top-down**: Create spaces first, then threads, then notes
2. **Bottom-up**: Create notes first, then organize them into threads and spaces later

Most people use a hybrid approach - create some structure but also capture quickly and organize later.

### Can I move notes between threads?

Yes! Open the note, click the "More" menu (three dots), select "Edit", and choose a new thread. You can also add notes to multiple threads.

### Can I move threads between spaces?

Yes! Open the thread, click the "More" menu (three dots), select "Edit", and choose a new space. All notes in the thread will move with it.

## Note IDs

### What are note IDs?

Every note gets a sequential ID like N001, N002, N003. These are user-friendly identifiers that make it easy to reference notes in conversations or study groups.

### Why are note IDs sequential?

Sequential IDs are easier to remember and reference than random database IDs. "Check out my insight in N015" is much clearer than "Check out note_1756318000001".

### Can I change a note's ID?

No, note IDs are permanent and sequential. They help maintain order and prevent confusion. If you delete N003, the next note will be N004 (not N003 again).

### What happens if I delete a note?

Notes are never permanently deleted. When you delete a thread, its notes move to "Unorganized" in "For You". This prevents accidental loss of important insights.

## Data Safety

### Are my notes safe?

Yes! Your notes are:
- **Private**: Only you can see them
- **Secure**: Protected by Clerk authentication
- **Backed up**: Database is automatically backed up
- **Never deleted**: Notes are preserved, not deleted

### Can I lose my notes?

No. Notes are never permanently deleted. Even if you delete a thread, all its notes are moved to "Unorganized" where you can find them again.

### Is my data backed up?

Yes, the database is automatically backed up by Turso. Your content is safe and secure.

### Can I export my notes?

Export functionality is coming in a future update. For now, your notes are safely stored in the cloud and accessible from any device.

## Features

### Does Harvous have search?

Yes! Use the search bar (or press `Cmd/Ctrl + F`) to search across all your notes and threads. Search includes title matches, content matches, and tag matches.

### Can I format my notes?

Yes! Harvous uses a rich text editor with formatting options:
- Bold, italic, underline
- Ordered and unordered lists
- Clean, distraction-free interface

### What is the XP system?

XP (Experience Points) is a gamification system that rewards you for creating content and engaging with the app. You earn XP for creating notes (10 XP), creating threads (10 XP), and opening content (1 XP, up to 50 per day).

### Can I share my notes with others?

Shared spaces are coming soon! For now, all spaces are private. Future features will include collaboration and sharing.

### Does Harvous work offline?

Harvous is a Progressive Web App (PWA) with offline support. You can access your notes offline, and changes will sync when you're back online.

## Technical Questions

### What browsers does Harvous support?

Harvous works on all modern browsers:
- Chrome, Firefox, Safari, Edge
- Mobile browsers (iOS Safari, Chrome Mobile)
- Desktop and tablet browsers

### Do I need to install anything?

No installation required! Harvous works in your web browser. However, you can install it as a PWA for an app-like experience on mobile and desktop.

### How do I install Harvous as an app?

**Mobile:**
1. Visit Harvous in your browser
2. Look for "Add to Home Screen" prompt
3. Tap to install

**Desktop:**
1. Visit Harvous in your browser
2. Look for install icon in address bar
3. Click to install

### Does Harvous work on tablets?

Yes! Harvous is fully responsive and works great on tablets with a touch-optimized interface.

## Troubleshooting

### I can't find my note. Where did it go?

Check these places:
1. **"For You" tab**: It might be unorganized
2. **Search**: Use search to find it by title or content
3. **Thread**: Check the thread you assigned it to
4. **Space**: Browse the space it belongs to

### My search isn't working. What should I do?

1. **Check spelling**: Make sure keywords are spelled correctly
2. **Try different terms**: Use synonyms or related words
3. **Search by ID**: If you know the note ID, search for it directly
4. **Browse manually**: Sometimes browsing is faster than searching

### I can't save my note. What's wrong?

1. **Check your connection**: Make sure you're connected to the internet
2. **Try again**: Sometimes a retry helps
3. **Refresh the page**: A refresh can fix temporary issues
4. **Check for errors**: Look for error messages or notifications

### My profile changes aren't saving. Why?

1. **Check your connection**: Make sure you're connected to the internet
2. **Save again**: Click "Save" again to retry
3. **Refresh the page**: Sometimes a refresh helps sync changes
4. **Check other devices**: See if changes appear on other devices
