Teachers don’t need another inspirational quote about preparation. You need a stack you can run every week.

Five layers:

  1. Passage — precise enough to find later (John 15:1–11).
  2. Aim — one sentence for Wednesday, not five objectives.
  3. Questions — usually two: see, then seek (optional third: step).
  4. Trail — cross-references used, what landed, ties to last week.
  5. Return — the smallest midweek reopen (reread the aim; one group text; five verses again).

Return is how learning lasts. Retrieval practice research keeps saying: bringing something back beats highlighting it once.

QUESTIONS: 1. 2.
