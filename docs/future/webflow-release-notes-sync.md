# Syncing Release Notes to Webflow

> **Retired (2026):** Changelog publishing moved to the Astro marketing site ([harvouscom/harvous.com](https://github.com/harvouscom/harvous.com), `data/webflow-changelog.csv`). Webflow changelog sync scripts and the post-commit hook integration were removed. This doc is kept for historical context only.

## Overview

This document outlines the plan to sync user-friendly release notes from `release-notes/` to Webflow CMS, complementing the existing commit-level changelog sync.

## Current State

### Existing: Commit-Level Changelog Sync

**Script:** `scripts/sync-changelog-to-webflow.js`

**How it works:**
- Syncs after each commit via git hook
- Creates one Webflow entry per commit
- Maps commit types to categories (Feature, Fix, Improvement)
- Adds light user-friendly intros: "We've added a new feature: [message]"
- Skips internal/technical commits

**Webflow Collection:** Changelog
- Fields: version, date, commit-message (HTML), category
- Collection ID: `6914bfd8c7facb8fa00eaad3`

**Limitations:**
- Still somewhat technical (based on commit messages)
- One entry per commit (can be noisy)
- Doesn't group related changes
- Lacks "how it helps you" benefit language

### New: Release Notes (Not Yet Synced)

**Location:** `release-notes/`

**Format:**
- One file per version (e.g., `v1.13-january-2026.md`)
- Groups changes by user-facing categories
- "What changed" + "How it helps you" sections
- Tips and examples
- Plain English, benefit-focused

**Generated by:** `scripts/generate-release-notes.js` (automatic)

## Proposed Solution: Hybrid Approach

### Why Hybrid?

Keep both systems because they serve different audiences:

| Aspect | Commit-Level Changelog | Release Notes |
|--------|----------------------|---------------|
| **Audience** | Developers, power users | All users |
| **Frequency** | Per commit | Per version |
| **Detail** | Granular, technical | Grouped, benefit-focused |
| **Use Case** | "Recent Updates" feed | "What's New" page |
| **Language** | Technical with light cleanup | Plain English |

### Architecture

```
Webflow CMS:
├── Changelog Collection (existing)
│   ├── Per-commit entries
│   ├── Fields: version, date, commit-message, category
│   └── Use: Activity feed, detailed changelog
│
└── Release Notes Collection (new)
    ├── Per-version entries
    ├── Fields: version, date, title, content, highlights
    └── Use: Main "What's New" page, announcements
```

## Implementation Plan

### Phase 1: Create Webflow Collection

**Collection Name:** Release Notes

**Fields:**
- `version` (Plain Text) - e.g., "1.13.0"
- `version-slug` (Plain Text) - e.g., "v1-13" (for URL)
- `release-date` (Date) - Publication date
- `title` (Plain Text) - e.g., "What's New in Harvous v1.13"
- `summary` (Plain Text) - One-line summary
- `content` (Rich Text) - Full release notes in HTML
- `highlights` (Multi-reference or Plain Text) - Key features
- `category-tags` (Multi-reference) - Navigation, Performance, etc.
- `is-published` (Boolean) - Draft vs. published
- `month-year` (Plain Text) - e.g., "January 2026" (for grouping)

**Slug:** Auto-generate from version-slug

### Phase 2: Create Sync Script

**Script:** `scripts/sync-release-notes-to-webflow.js`

**Functionality:**
1. Read release note markdown from `release-notes/`
2. Parse markdown to extract:
   - Version
   - Date
   - Content sections
   - Categories
3. Convert markdown to HTML (preserve formatting)
4. Create/update Webflow CMS item
5. Set as draft (for manual review before publishing)

**Trigger options:**
- Manual: `npm run release-notes:sync <version>`
- Automatic: Add to `bump-version.js` workflow
- CI/CD: Run on merge to main

**Example usage:**
```bash
# Sync specific version
npm run release-notes:sync 1.14.0

# Sync latest
npm run release-notes:sync
```

### Phase 3: Markdown to HTML Conversion

**Considerations:**
- Release notes use plain text only (no emoji in source markdown); conversion should not add decorative symbols.
- Convert markdown headings to HTML
- Handle bullet lists
- Preserve code blocks if any
- Convert links

**Libraries to consider:**
- `marked` - Simple markdown parser
- `markdown-it` - More features, plugins
- Custom parser - Full control

### Phase 4: Integration with Release Process

**Updated workflow:**
```bash
# Developer makes changes
git commit -m "feat: add awesome feature"

# Automatic version bump
npm run version:bump
# ✅ Bumps version
# ✅ Generates technical changelog
# ✅ Generates user-friendly release notes

# Optional: Sync to Webflow
npm run release-notes:sync
# ✅ Creates draft in Webflow Release Notes collection

# Manual: Review and publish in Webflow CMS
```

## Script Outline

### `scripts/sync-release-notes-to-webflow.js`

```javascript
#!/usr/bin/env node

/**
 * Release Notes Sync to Webflow CMS
 * 
 * Syncs user-friendly release notes to Webflow for public display.
 * Creates one entry per version in the Release Notes collection.
 */

import { readFileSync, readdirSync } from 'fs';
import { join } from 'path';
import { marked } from 'marked'; // or markdown-it

// Configuration
const WEBFLOW_RELEASE_NOTES_COLLECTION_ID = 'TBD'; // Create collection first
const WEBFLOW_API_BASE = 'https://api.webflow.com/v2';

// Main functions:
// 1. findReleaseNoteFile(version) - Find the markdown file
// 2. parseReleaseNote(filePath) - Extract metadata and content
// 3. convertMarkdownToHTML(markdown) - Convert to HTML
// 4. extractHighlights(content) - Pull out key features
// 5. createWebflowItem(data) - Create CMS entry
// 6. main(version) - Orchestrate the sync

// Example structure:
async function main(version) {
  // Find release note file
  const filePath = findReleaseNoteFile(version);
  
  // Parse markdown
  const { metadata, content, categories } = parseReleaseNote(filePath);
  
  // Convert to HTML
  const htmlContent = convertMarkdownToHTML(content);
  
  // Extract highlights
  const highlights = extractHighlights(content);
  
  // Create Webflow item
  await createWebflowItem({
    version: metadata.version,
    date: metadata.date,
    title: metadata.title,
    content: htmlContent,
    highlights: highlights,
    categories: categories,
    isDraft: true // For manual review
  });
  
  console.log(`✅ Release notes synced to Webflow: v${version}`);
}
```

## Environment Variables

**Required:**
